# Wallpaper

Inserisci in questa cartella le immagini tra cui scegliere (i file qui inseriti sono ignorati da git e rimangono locali alla macchina).
Sono supportati i formati JPG, JPEG, PNG, WebP, JXL e AVIF.

- Durante l'installazione iniziale, il setup configura automaticamente la prima immagine valida trovata in questa cartella (con qualsiasi nome file) o in `~/Pictures`, oppure lo sfondo scuro predefinito di sistema o generato.
- Per cambiare lo sfondo in qualsiasi momento tra quelli disponibili usa:

```bash
./install.sh --set-wallpaper
```
oppure:
```bash
workstation-wallpaper
```
